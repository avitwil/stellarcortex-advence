# Phase P1: Foundation

Exit criterion (section 8): "Login + pairing + an empty chat round-trip on desktop and Android."

## What was built
- **Monorepo** (pnpm, Node 22, TypeScript): `packages/protocol`, `apps/server`, `apps/ui`,
  `apps/desktop`, `apps/android`, `images/bot-computer`, `tests/e2e`.
- **Server** (Fastify + ws + better-sqlite3): TLS 1.3-only HTTPS on one port (D-17),
  self-generated ECDSA P-256 key, master key wrapped by the OS keystore or an Argon2id
  passphrase, XChaCha20-Poly1305 secret store, pairing, Google OIDC (PKCE, ID-token
  verification), allowlist, 15-minute sessions refreshed by device signature, signed
  WebSocket with heartbeat, log redaction, encrypted key backup/restore, CLI
  (`advence serve | pair | admin reset/devices/revoke | backup | restore | unlock`).
- **Protocol package:** encoding, hashing/HKDF, AEAD, Argon2id wrap, Ed25519 request and
  frame signing, pairing link + 6-digit code, zod API schemas.
- **UI** (React 18 + Vite): connect (QR scan or link), pairing code, Google setup wizard,
  login, sidebar shell, Settings with every FR-UI-07 section (P1 ones functional), own
  logo and icons, Hebrew RTL + English, light/dark/system theme, strict CSP + SRI.
- **Desktop shell** (Electron 45): `app://` scheme, sandbox, context isolation, CSP
  `connect-src 'self'`; all server traffic goes through main-process pinned HTTPS/WS
  (DL-016); loopback Google login; fuses (RunAsNode off, asar integrity, only-asar);
  AppImage + deb build on Linux, NSIS/DMG builds in the `installers` workflow.
- **Android shell** (Capacitor 8, Android 9+): native pinned OkHttp (TLS 1.3 via
  Conscrypt), Android Keystore secure store, Credential Manager Google sign-in, backups
  disabled, no cleartext, own icons; arm64 + x86_64 + universal APKs built in CI.
- **CI** (`.github/workflows/ci.yml`): typecheck, brand check, license audit, unit and
  E2E tests, bot computer image build + smoke, Linux desktop packages, APKs + Android 9
  emulator smoke test. Nothing is published (C-07).

## Review
Correctness review and appsec review were run on the whole P1 codebase. Findings fixed,
each with a regression test where testable:
sign-out now unbinds the device (refresh needs Google again); removing a member who had
signed in no longer fails on a foreign key; WebSocket events stop when a session expires
or ends; the client computes the pairing code itself (MITM shows a different code);
pins are per host and port; the client socket no longer opens two connections after a
dead stream; the desktop loopback sign-in can be retried; desktop WebSocket ids are
scoped per renderer; the macOS keychain gets the master key over stdin, not argv; the
browser key store uses one IndexedDB connection and a race-free wrap key.
